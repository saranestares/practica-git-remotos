# practica-git-remotos
# Práctica de GitHub

## Descripción del proyecto

Este repositorio forma parte de las actividades de la asignatura **Despliegue de Aplicaciones Web**.

En él trabajaremos con Git, GitHub y diferentes herramientas de desarrollo.

### Objetivos

Con esta práctica aprenderemos a:

- Crear y gestionar repositorios.
- Trabajar con ramas.
- Resolver conflictos.
- Publicar páginas web.
